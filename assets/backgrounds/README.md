# Channel backgrounds

Drop one photo per channel here, then uncomment the matching line in the
"Per-channel photo backdrop" block near the end of the `<style>` in `index.html`.

Expected file names: `sports.webp`, `betting.webp`, `movies.webp`, `anime.webp`,
`games.webp`, `politics.webp`, `bowling.webp`, `music.webp`, `creator.webp`, `live.webp`.

- WebP (or JPEG), about 1920px wide, 150–250 KB. The backdrop is blurred, so heavy compression is fine.
- Use photos you took or have the rights to (Unsplash/Pexels licenses are fine). The site is public.
- The K-pop channel needs no file: it uses the featured release's album art automatically.
